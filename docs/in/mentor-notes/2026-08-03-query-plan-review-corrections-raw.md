# Уточнения наставника к плану запросов

Дата: 2026-08-03.

Статус: входящие замечания к документам итерации от 2026-08-03.

## Замечания

1. Убрать бессодержательное повторение трех одинаковых пунктов `1 час — решаешь вопросы`; у трех часовых
   подходов к `1С:Профессионал` должна быть понятная структура.
2. Приложить переданную наставником внешнюю обработку `Консоль запросов УФ.epf` и использовать ее для практики.
3. Все учебные запросы вести в одном списке консоли, сохранять из консоли в один файл и прикладывать этот файл
   в качестве решения.
4. Добавить обязательные упражнения на секцию `ИМЕЮЩИЕ`: она часто вызывает трудности у начинающих и должна
   отрабатываться отдельно с обращением к документации по языку запросов.
5. Добавить пакетные запросы и временные таблицы как обязательный материал, а не самостоятельный максимум или
   тему «на потом».
