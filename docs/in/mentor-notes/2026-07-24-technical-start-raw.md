## Уточнение наставника

Дата: 2026-07-24.

- Платформа у Алексея уже установлена; ее установка не входит в план.
- Нужны не 10–15 горячих клавиш, а все полезные хоткеи из перечня.
- Освоение хоткеев — длительная практика: не нужно пытаться выучить их за один раз, нужно постепенно перестраивать мышление и привычные действия в пользу клавиатуры.
- Хоткеи имеют принципиальное значение, потому что дают огромную накопительную экономию времени.
- Основной маршрут наставника должен оставаться видимым; вспомогательные источники нельзя смешивать с его этапами.
- Синтакс-помощник открывается в конфигураторе по `Ctrl+F1`.
- По коллекциям нужно идти в ветку `Универсальные коллекции значений`; `COMSafeArray` в маршрут не включать.
- По глобальному контексту нужно пройти `Функции преобразования значений` и разделы функций работы со значениями типов `Дата`, `Строка`, `Тип`, `Число`.
- Для пункта 3 нужно подготовить самостоятельные задачи; глубоких знаний механизмов 1С для них не требуется.
- Для решений нужен отдельный каталог с подкаталогами: Алексей решает задачи и складывает файловые выгрузки конфигураций или обработок в папки соответствующих задач.
- Материалы этого проекта со временем лягут в образовательную программу, поэтому даже небольшие рабочие уточнения нужно добавлять в программу, а не оставлять только в переписке.
- В Git-методичке нужно явно зафиксировать получение изменений через Git Bash командой `git pull origin main`.
- В набор устанавливаемых инструментов добавить Notepad++ и Obsidian.
- В список обязательных доступов стажера добавить VPN КОРУС, Confluence КОРУС и AI-ассистент КОРУС.
- Уточнение по сдаче решений от 2026-07-29: `submission.md`, `submission.txt` и отдельные отчеты не требуются; сдача идет через единый каталог с файловой выгрузкой внешней обработки.
- По третьей встрече добавить в программу правила код-ревью: нейминг по смыслу, отсутствие совпадений с глобальным контекстом, типизация колонок через `ОписаниеТипов`, отсутствие магических чисел, использование типовых методов платформы, длина строки до 120 символов.
- После завершения первого блока алгоритмов переводить Алексея к подготовке к `1С:Профессионал`: тренажер `1С-ник`, подписка/доступ и регулярное нарешивание.
