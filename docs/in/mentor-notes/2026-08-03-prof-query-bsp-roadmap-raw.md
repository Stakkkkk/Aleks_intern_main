# Сырые вводные наставника: Проф, запросы, практика, БСП

Дата фиксации: 2026-08-03.

Статус: входящие заметки наставника. На основе этих вводных подготовлены рабочий план наставника и выдаваемые материалы для Алексея.

## Исходная рамка

Первичная разработка закончена. Подготовка к `1С:Профессионал` начата. Алексей нарешивает тесты.

## Неделя до 2026-08-07

Фокус: запросы + `1С:Профессионал`. По Профу — прорешать все вопросы в один заход.

### Освежить стандарты по итогам разработки

Наставник будет спрашивать:

- <https://its.1c.ru/db/v8std/content/454/hdoc>
- <https://its.1c.ru/db/v8std#content:647:hdoc>
- <https://its.1c.ru/db/v8std#content:641:hdoc>
- <https://its.1c.ru/db/v8std/content/442/hdoc>

### Проф

Нарешивать вопросы `1С:Профессионал` не менее 3 часов в день: 3 подхода по 1 часу.

### Запросы

Теория — один день, дальше практика. К четвергу ожидается уверенное ориентирование в консоли запросов и конструкторе запросов.

Источники:

- курс на платформе КОРУС: <https://edu.korusconsulting.ru/course/view.php?id=870>
- текст: главы 1 и 2 <https://its.1c.ru/db/pubqlang#content:54:hdoc>
- документация, обязательно раздел 8.4.17: <https://its.1c.ru/db/v8327doc#bookmark:dev:TI000000492>
- практические задачи в файловой базе `1С:УНФ демо`: <https://online.1c.ru/catalog/programs/program/28814183/>

Нужна помощь агента: написать упражнения по запросам 1С.

## Неделя до 2026-08-14

Фокус: много практики + `1С:Профессионал`. Целевой ориентир по Профу: 60% без ошибок.

- обработчики событий и подписки на события:
  - <https://infostart.ru/1c/articles/1098803/>
  - <https://xn----1-bedvffifm4g.xn--p1ai/articles/%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D0%B8-%D0%BD%D0%B0-%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D1%8F/>

Отдельная практика: посмотреть порядок вызовов в демо УНФ на живых справочниках и документах — при открытии, закрытии, записи, проведении.
