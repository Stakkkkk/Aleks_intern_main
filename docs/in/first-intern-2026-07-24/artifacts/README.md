# Артефакты стажёра

В этот каталог складываются рабочие результаты диагностики и практики.

Примеры:

- `day-01-diagnostic.md` — карта бизнес-сценария, карта метаданных, карта пробелов.
- `professional-gap-map.md` — карта подготовки к `1С:Профессионал`.
- `process-map.md` — описание выбранного бизнес-процесса.
- `metadata-map.md` — карта объектов метаданных.
- `agent-prompts.md` — разбор хороших и плохих агентских запросов стажёра без персональных данных.

Не складывать сюда ФИО, контакты и сырые кадровые оценки. Для чувствительных заметок использовать локальный `../private/`.
