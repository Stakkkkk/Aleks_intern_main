# Решение задачи NN. Название

## Условие своими словами

сначала очистить массив от пустых строк и лишних пробелов, потом через соответсвие убрать дубликаты и добавить данные в новый массив

## Алгоритм


1. проверка элемента массива на наличие лишних пробелов
2. изменение элемента с убавлением лишних пробелов
2. проверка элемента массива на заполненность
3. при обнаружении пустого элемента массива он игнорируется
4. в соотвествие добавляются уникальные элементы массива и добавляются в новый массив
5. выводится новый отсортированный массив

## Типы и коллекции

Нашмассив - массив для неотсортированных значений
массивСорт - массив для уникальных значений 
СоответствиеСорт - соответствие для уникальных ключей

## Реализация

- Вариант: конфигурация 
- Каталог файловой выгрузки: `configuration/`.
