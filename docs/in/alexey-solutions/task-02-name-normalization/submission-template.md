# Решение задачи NN. Название

## Условие своими словами

сначала очистить массив от пустых строк и лишних пробелов, потом через соответсвие убрать дубликаты

## Алгоритм


1. проверка элемента массива на наличие лишних пробелов
2. проверка элемента массива на заполненность
3. при обнаружении пустого элемента массива его удалить
4. через соотвествие сравнить элементы массива
5. удалить дубликаты
