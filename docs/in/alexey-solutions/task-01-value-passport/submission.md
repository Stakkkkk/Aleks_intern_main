# Решение задачи 01. Паспорт значения

## Условие своими словами

написать программу принимающую значение от пользователя, после чего возвращающую структуру с информацию о нём 


## Алгоритм

<!-- Описать последовательность действий до кода. -->

1. программа принимает на вход значение;
2. программа создаёт структуру;
3. программа заполняет структуру;
3. программа выводит заполненную структуру.

## Типы и коллекции

структура - главная коллекция программы. Нужна для хранения наименования данных и их значения
массив - для проверки работы в качестве значения

## Реализация

- Вариант: конфигурация 
- Каталог файловой выгрузки: `configuration/` .
