# Решение задачи 3. Название Календарь периода

## Условие своими словами

написать функцию которая принемает 2 даты, находит количество дней между ними и добавляет их в таблицу значений

## Алгоритм

<!-- Описать последовательность действий до кода. -->

1. функция принемает на вход дату начала и дату окончания
2. Если дата начала больше даты окончания программа создаёт строчку в таблице значений
3. с помощью встроенных функция таблица значений заполняется
4. в конце цикла к текущей дате прибавляется 86400 секунд 

## Типы и коллекции
