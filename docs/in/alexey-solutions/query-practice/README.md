# Практика запросов

В этой папке Алексей сохраняет решение по заданию `docs/out/alexey-query-practice-unf.md`.

Все задачи нужно вести в одном списке приложенной консоли запросов. После работы весь список сохраняется командой
консоли `Сохранить запросы в файл` и прикладывается сюда одним файлом.

Рекомендуемое имя:

```text
alexey-query-practice.<расширение консоли>
```

Расширение, которое предложит консоль, менять не нужно. Каждая задача внутри файла должна быть отдельным запросом
с именем вида `XX. Короткое название`. В начале текста запроса:

```text
// Задача:
// Источники данных:
// Параметры:
// Что проверил:

ВЫБРАТЬ
    ...
```

Конструктор запросов может удалить комментарии, поэтому этот блок нужно проверить после последнего использования
конструктора.

Отдельные отчеты не нужны. На приемке Алексей объясняет запросы словами.
