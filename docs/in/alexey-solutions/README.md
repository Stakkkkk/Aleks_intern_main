# Решения Алексея

В этой папке хранится сдаваемое решение практических задач.

## Текущая структура

```text
External_result/
└── файловая выгрузка внешней обработки
```

`External_result/` — единый каталог сдачи. В него помещается файловая выгрузка внешней обработки, в которой реализованы задачи.

Отдельные `submission.md`, `submission.txt` и отчеты по задачам больше не требуются.

Нужна именно **файловая выгрузка исходников**, пригодная для просмотра изменений в Git. Одного бинарного файла `.cf`, `.epf` или `.erf` недостаточно.

Рабочий формат для первого блока алгоритмов: одна внешняя обработка, в которой каждая задача запускается отдельной кнопкой или явно названной процедурой. Связь задачи с кодом должна быть понятна из имен кнопок, процедур и комментариев в коде.

## Порядок сдачи

1. Выполнить задачу и проверить ее на заявленных тестах.
2. Выгрузить внешнюю обработку в файловый вид.
3. Положить или обновить выгрузку в `docs/in/alexey-solutions/External_result/`.
4. Выполнить `git status` и убедиться, что в изменениях только файловая выгрузка обработки и согласованные учебные материалы.
5. Зафиксировать и отправить изменения по согласованной с наставником схеме работы через Git.

На приемке Алексей должен уметь словами объяснить алгоритм, тесты, выбранные типы и коллекции. Отдельный файл отчета для этого не создается.
