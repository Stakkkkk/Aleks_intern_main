# Решение задачи NN. Название

## Условие своими словами

Программа получает таблицу проходится по ней, потом по ключу записывает уникальные строчки в новую таблицу и если встретит неуникальную строчку по ключу найдёт что уже есть и изменит сумму и количество

## Алгоритм

1. Программа получает таблицу
2. Программа создаёт новую таблицу значений
3. программа проходится по таблице
4. Программа создаёт уникальный ключ для каждой новой записи
5. При встрече ключа в новой записи программа меняет уже существующую запись
6. программа возвращает новую таблицу значений

## Типы и коллекции

Таблица значений входная - входная таблица с необработанными данными
соответствие  - соответствие с уникальным ключом для сортировки данных
таблица значений выходная - таблица с отсортированными данными

## Реализация

- Вариант:  внешняя обработка.
- Каталог файловой выгрузки:  `external-processing/`.
