# Решение задачи 4. Частотный словарь

## Условие своими словами

программа должна принять массив кодов, нормализовать их убрав пробелы и перевести всё в заглавные потом вывести статистику о каждом уникальном значении

## Алгоритм

<!-- Описать последовательность действий до кода. -->

1. фуниция принемает массив на вход
2. убираются все лишние пробелы и все строчные буквы становятся заглавными
3. каждое значение становится уникальным ключом через соответствие
4. проводится подсчёт значений
5. выводится информация о них

## Типы и коллекции

массив - для последующей обработки
соответствие - для решения пункта о уникальности заданых символов. Так же для их подсчёта

## Реализация

- Вариант:  внешняя обработка.
- Каталог файловой выгрузки: `external-processing/`.

       B-02 — 2 раза, первая позиция 2 | А-01 - 3 раз, первая позиция 0, В-02 - 2 раз первая позиция 2  как и ожидалось|

## Синтакс-помощник

Массивы - для разъеснения некоторых моментов и возможностей
соответствия - для получения способов взаимодействия с ними а так же для более глубокого изуения их возможностей
