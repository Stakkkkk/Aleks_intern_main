# Документы проекта

В этой папке хранятся проектные артефакты по работе со стажером Алексеем.

## Рабочие зоны

- `in/` — входящие извне материалы: транскрибы встреч, handoff, исходные заметки, документы, выгрузки и другие принесенные артефакты.
- `lib/` — рабочая библиотека проекта: устойчивые факты, решения, карта пробелов, планы действий, очищенные выдержки и материалы, которые реально используются в работе.
- `out/` — исходящие материалы: документы, задания, отчеты, схемы и другие результаты, подготовленные для передачи стажеру, наставнику или наружу.

Папки считаются живыми: материал может перейти из `in/` в `lib/` или `out/`, когда меняется его статус. Исходные и промежуточные материалы после преобразования удаляются только после явного подтверждения наставника.

## Текущий режим

- Агент используется только наставником.
- Стажеру не передаются агентские инструкции, промпты и рабочий доступ до сдачи `1С:Профессионал` или отдельного решения наставника.
- Синхронизация проектных материалов идет через Git и репозиторий `Stakkkkk/Aleks_intern_main`.
- Персональные данные, контакты, личные обстоятельства и кадровые оценки не фиксируются без явной команды наставника.

## Актуальные исходящие материалы

- `out/alexey-git-install-and-clone.md` — установка Git и клонирование репозитория.
- `out/alexey-technical-start-plan.md` — технический старт: конфигуратор, KDiff3, типы, коллекции, алгоритмы и запросы.

  `1С:Специалист`, оценки и общие критерии работы; конкретные практические задачи назначает наставник.
- `out/alexey-task-pool-2026-08-27--2026-09-04.md` — назначенный практический пул: расширение, новый документ,
  проведение, подсистемы БСП и печатные формы с обязательными требованиями к качеству и оценкам.
- `out/alexey-work-estimation-template.md` — шаблон предварительной оценки задачи и разбора отклонения от факта.
- `out/alexey-metadata-map.md` — краткая карта объектов метаданных и модулей для навигации во время первого
