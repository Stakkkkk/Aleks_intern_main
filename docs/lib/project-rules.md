# Рабочие правила проекта

Дата фиксации: 2026-07-24.

## Фокус проекта

Проект ведется для сопровождения работы со стажером Алексеем: диагностика уровня, подготовка встреч, практические задания, карта пробелов и подготовка к `1С:Профессионал`.

## Роль агента

Агент пока используется только наставником. Для стажера агентский доступ не включается до выполнения условия наставника: сдачи `1С:Профессионал`, либо до отдельного явного решения наставника.

Следствие для документов: не готовить для стажера инструкции по агентской работе как текущий рабочий процесс. Можно фиксировать, какие вопросы и проверки наставник готовит с помощью агента.

## Git-синхронизация

Рабочая синхронизация проекта идет через GitHub-репозиторий `Stakkkkk/Aleks_intern_main`.

В Git должны попадать проектные материалы из `docs/`, `.gitignore` и будущая стандартная конфигурация проекта. Локальный агентский обвес (`AGENTS.md`, `.agent/`, `.agent-io-safety/`) не коммитится.

## Документооборот

- Сырые транскрибы встреч и входящие материалы сначала складываются в `docs/in/`.
- Решения Алексея принимаются в `docs/in/alexey-solutions/`: одна задача — один каталог с отчетом и файловой выгрузкой конфигурации либо внешней обработки.
- Устойчивые выводы и рабочие материалы оформляются в `docs/lib/`.
- Материалы для передачи наружу готовятся в `docs/out/`.
- Если входящий материал преобразован в стабильный рабочий материал, связь между исходником и результатом фиксируется в ближайшем контекстном документе.
- Удаление исходных или промежуточных артефактов после преобразования выполняется только после явного подтверждения наставника.

## Персональные данные и наблюдения

Без отдельной команды наставника не фиксировать ФИО, контакты, паспортные данные, личные обстоятельства и кадровые оценки.

В наблюдениях отделять факты от интерпретаций: записывать, что стажер сказал, сделал, проверил, где затруднился и как отреагировал на обратную связь.
