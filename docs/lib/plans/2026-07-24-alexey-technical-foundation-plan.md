# План технического старта Алексея

Дата подготовки: 2026-07-24.

Источник: `docs/in/mentor-notes/2026-07-24-technical-start-raw.md`.

Статус: рабочий план наставника. Выдаваемая версия для Алексея: `docs/out/alexey-technical-start-plan.md`.

## Цель

За первую фазу вывести Алексея в рабочий технический режим: настроенный конфигуратор, базовая ориентация в Git, KDiff3 как инструмент сравнения, понимание типов и коллекций 1С, первые самостоятельные алгоритмы на встроенном языке и подготовка к плотному блоку по запросам.

План не заменяет подготовку к `1С:Профессионал`, а создает базу, чтобы вопросы экзамена разбирались не как набор ответов, а как практические механизмы платформы.

## Порядок прохождения

### Этап 0. Git и доступ к материалам

Условие входа: Алексей установил Git и склонировал репозиторий по инструкции `docs/out/alexey-git-install-and-clone.md`.

Результат:

- локально есть папка `Aleks_intern_main`;
- команда `git status` выполняется без ошибок;
- Алексей понимает базовые команды `git pull`, `git status`, `git add`, `git commit`;
- уровень доступа к репозиторию согласован отдельно: только чтение, прямой push или fork/PR.

### Этап 1. Настройка рабочего места 1С

Источники:

- настройка конфигуратора: <https://infostart.ru/1c/articles/2192029/>
- горячие клавиши: <https://its.1c.ru/db/v8std/content/430/hdoc>
- KDiff3: <https://kdiff3.sourceforge.net/>

Задачи:

1. Установить или проверить установленную платформу 1С 8.3, когда наставник даст точную версию.
2. Настроить рабочее пространство конфигуратора по статье: параметры текста, читаемый шрифт, отступы, отображение служебной информации и удобство навигации.
3. Выписать 10-15 горячих клавиш, которые реально будут использоваться в ежедневной работе.
4. Установить KDiff3 и проверить, что он открывается.
5. Зафиксировать, что именно настроено и где возникли вопросы.

Контрольный результат:

- короткий отчет Алексея: какие настройки сделаны, какие хоткеи выбраны, KDiff3 установлен или нет;
- если что-то не получилось, вопрос оформлен по шаблону "шаг, команда/действие, ожидание, факт, ошибка".

### Этап 2. Базис: типы и коллекции

Источники:

- практическое пособие разработчика 1С 8.3: <https://its.1c.ru/db/pubdevguide83>
- руководство разработчика, метаданные: <https://its.1c.ru/db/v8327doc#bookmark:dev:TI000000020>
- универсальные коллекции значений: <https://xn----1-bedvffifm4g.xn--p1ai/articles/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D1%83%D0%BD%D0%B8%D0%B2%D0%B5%D1%80%D1%81%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%BE%D0%BB%D0%BB%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%D0%BC%D0%B8/>

Что разобрать:

- базовые типы значений: строка, число, дата, булево, неопределено, null, ссылка, объект;
- составные типы и описание типов;
- универсальные коллекции: массив, фиксированный массив, структура, фиксированная структура, соответствие, список значений, таблица значений, дерево значений;
- когда какая коллекция подходит и почему;
- отличие хранения значения, ссылки и объекта;
- что такое метаданные и как они связаны с объектами конфигурации.

Контрольный результат:

- конспект "типы и коллекции" с короткими определениями своими словами;
- таблица "коллекция -> когда использовать -> типичная ошибка";
- 5-7 мини-примеров кода.

### Этап 3. Глобальный контекст и функции работы с типами

Источник: синтакс-помощник 1С, разделы глобального контекста и функций работы со значениями.

Что разобрать:

- `ТипЗнч`, `Тип`, `ОписаниеТипов`;
- `ЗначениеЗаполнено`;
- преобразования `Строка`, `Число`, `Дата`;
- работа с форматированием;
- проверка типа перед обработкой значения;
- аккуратная обработка `Неопределено` и `Null`;
- сообщения пользователю и простая диагностика результата.

Контрольный результат:

- функция-описатель значения: принимает любое значение и возвращает строку с типом, заполненностью и человекочитаемым представлением;
- набор тестовых значений для проверки функции.

### Этап 4. Первые алгоритмы на встроенном языке

Цель: отделить знание синтаксиса от умения разложить задачу на последовательность действий.

Задачи для самостоятельного решения:

1. Инспектор значений.
   Принять массив разных значений и вывести по каждому тип, заполненность и строковое представление.

2. Сумма строк табличной части.
   Есть таблица значений с колонками `Номенклатура`, `Количество`, `Цена`. Посчитать сумму по каждой строке и общий итог.

3. Группировка по ключу.
   Есть таблица значений с `Номенклатура`, `Склад`, `Количество`. Свернуть строки до итогов по паре `Номенклатура + Склад`.

4. Поиск дублей.
   Есть массив кодов. Найти повторяющиеся коды и количество повторов.

5. Нормализация строк.
   Есть список строк с пробелами и разным регистром. Очистить пробелы, привести к единому виду, удалить пустые значения.

6. Распределение суммы пропорционально коэффициентам.
   Есть общая сумма и таблица коэффициентов по получателям. Распределить сумму пропорционально, округлить до двух знаков и остаток от округления отдать последнему или самому крупному получателю. Отдельно объяснить, почему остаток появляется.

7. Расчет упаковок и грузовых мест.
   Есть количество товара и коэффициент упаковки. Посчитать количество полных упаковок, остаток и количество грузовых мест.

8. Распределение отгрузки по остаткам.
   Есть потребность отгрузить N единиц и таблица остатков по складам. Распределить количество по складам по порядку строк и показать недопоставку, если остатков не хватило.

9. Топ-N по сумме.
   Есть таблица продаж. Вывести N номенклатур с максимальной суммой.

10. Контроль входных данных.
    Для таблицы строк проверить обязательные поля, отрицательные количества, нулевые коэффициенты и некорректные даты. Вернуть список ошибок.

Для каждой задачи Алексей должен сдавать:

- формулировку задачи своими словами;
- алгоритм шагами до кода;
- код;
- 3-5 тест-кейсов;
- короткий вывод: что было непонятно, что пришлось подсмотреть.

### Этап 5. Запросы: теория

Источник: <https://its.1c.ru/db/pubqlang>.

Режим: "жестко раскурить"; в языке запросов нет мелочей.

Что выписать:

- структура запроса;
- выборка полей;
- псевдонимы;
- условия;
- группировка;
- агрегатные функции;
- сортировка;
- параметры;
- соединения;
- объединения;
- вложенные запросы;
- временные таблицы;
- пакетные запросы;
- обращение к табличным частям;
- работа с представлениями и ссылочными значениями;
- типичные ограничения и отличия от SQL.

Контрольный результат:

- конспект синтаксических структур;
- по каждому разделу 1-2 коротких примера;
- список вопросов, где смысл непонятен без практики.

### Этап 6. Запросы: практика

Статус: отложено.

Причина: варианты практики лучше накидывать после появления песочницы 1С и понимания состава учебной конфигурации.

Заготовка будущих направлений:

- выборка справочника;
- выборка документа и табличной части;
- остатки и обороты по регистрам;
- соединение документа с номенклатурой;
- группировка продаж;
- поиск дублей;
- контроль отрицательных остатков;
- временные таблицы для многошаговой выборки.

### Этап 7. Переход к `1С:Профессионал` и механизмам платформы

После базиса стартует подготовка к `1С:Профессионал`:

- первый круг вопросов;
- словарь непонятных терминов;
- привязка терминов к конфигуратору;
- нарешивание ошибок;
- параллельное движение по практическим механизмам.

Дальнейшие механизмы подбирать по связке "вопрос экзамена -> механизм платформы -> практическая задача".

## Риски и контроль

- Риск: Алексей начнет переписывать ответы без понимания. Контроль: каждый термин объясняется своими словами и связывается с местом в конфигураторе.
- Риск: Git станет отдельной большой темой. Контроль: на первом этапе нужен минимальный рабочий сценарий clone/pull/status, затем commit/push по отдельной команде.
- Риск: задачи по коду будут решаться "сразу кодом". Контроль: перед кодом требовать алгоритм шагами.
- Риск: запросы будут изучены поверхностно. Контроль: отдельный конспект всех синтаксических структур и практические задачи после подготовки песочницы.
