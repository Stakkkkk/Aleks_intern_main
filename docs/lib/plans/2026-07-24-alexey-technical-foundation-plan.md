# Технический маршрут Алексея: базис

Дата подготовки: 2026-07-24.

Источник: `docs/in/mentor-notes/2026-07-24-technical-start-raw.md`.

Статус: рабочий план наставника. Версия для Алексея: `docs/out/alexey-technical-start-plan.md`.

## Как читать этот документ

Ниже три разных слоя, которые нельзя смешивать:

1. **Маршрут** — порядок, в котором Алексей идет по темам.
2. **Справочная полка** — источники, куда он подсматривает по ходу работы; это не отдельные этапы обучения.
3. **Банк упражнений** — задания для закрепления типов, коллекций и глобального контекста. Он вынесен в отдельный документ и выдается порциями.

Git — способ синхронизации работы, а не этап технического базиса. Платформа 1С у Алексея уже установлена.

## В первую очередь: рабочее место

### 1. Настроить конфигуратор

Пройти настройки по статье: <https://infostart.ru/1c/articles/2192029/>.

Задача — привести уже установленный конфигуратор в состояние, пригодное для ежедневной разработки: код должен удобно читаться, навигация и служебная информация — помогать работе.

### 2. Начать осваивать все горячие клавиши

Основной источник: <https://its.1c.ru/db/v8std/content/430/hdoc>.

Цель — освоить **все горячие клавиши из перечня**, а не выбрать 10–15 штук. Это долгий рабочий процесс, а не упражнение на разовое заучивание.

Принцип освоения:

- изучить полный перечень и понимать, какие действия можно выполнять с клавиатуры;
- осваивать сочетания постепенно, группами и в реальной работе;
- замечать повторяющееся действие мышью, находить для него сочетание и сознательно переучиваться;
- регулярно возвращаться к полному перечню;
- стремиться выполнять типовые операции без мыши там, где это возможно и разумно.

Хоткеи важны не сами по себе: они экономят накопленное время и перестраивают способ работы с конфигуратором.

### 3. Установить KDiff3

Источник и дистрибутив: <https://kdiff3.sourceforge.net/>.

На этом шаге достаточно установить KDiff3, запустить его и уметь открыть сравнение двух файлов или каталогов. Практическое применение закрепится дальше при работе с изменениями.

## Во вторую очередь: базис

### 1. Типы в 1С и типы коллекций

Последовательность:

1. Разобраться с типами значений в 1С.
2. Разобраться с типами коллекций.
3. В синтакс-помощнике пройти универсальные коллекции значений.
4. Закрепить материал статьей: <https://xn----1-bedvffifm4g.xn--p1ai/articles/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D1%83%D0%BD%D0%B8%D0%B2%D0%B5%D1%80%D1%81%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%BE%D0%BB%D0%BB%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%D0%BC%D0%B8/>.

Смысл блока — не перечислить названия, а научиться определять тип значения, выбирать подходящую коллекцию и объяснять выбор.

### 2. Глобальный контекст: функции работы с разными типами

В синтакс-помощнике последовательно пройти функции глобального контекста, связанные с разными типами значений.

Нужно научиться не вспоминать функции наугад, а находить нужный раздел в синтакс-помощнике, читать сигнатуру, ограничения и примеры использования.

### 3. Алгоритмы и умение писать код

После пунктов 1 и 2 перейти к задачам на применение типов, коллекций и функций глобального контекста, затем добавить простые самостоятельные алгоритмы.

Банк упражнений хранится отдельно: `docs/lib/task-banks/2026-07-24-types-collections-and-algorithms.md`.

Задания выдаются по одному или небольшими сериями. Для каждого решения обязательны:

1. алгоритм словами до написания кода;
2. код;
3. тестовые примеры, включая граничные случаи;
4. короткое объяснение выбранных типов и коллекций.

### 4. Запросы: теория

Основной материал: <https://its.1c.ru/db/pubqlang>.

Язык запросов нужно разобрать полностью и внимательно: здесь нет мелочей. Алексей должен последовательно пройти материал и выписать **все синтаксические структуры**, а не только наиболее часто встречающиеся.

Итог блока — собственный структурированный конспект синтаксиса, к которому можно вернуться при решении задач.

### 5. Запросы: практика

Пока отложено. Практические варианты будут подготовлены отдельно после появления песочницы 1С и понимания ее состава.

## Потом

После базиса:

1. начинаем подготовку к `1С:Профессионал`;
2. параллельно идем дальше по механизмам платформы;
3. на каждый механизм даем практические задачи.
