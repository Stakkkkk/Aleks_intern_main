`36c9e98ada3da2ebb6507c8cbbde51667f76fcf8f7c1bb3c74fd946948d8b898`.

- выполнять запросы в режиме `1С:Предприятие` на данных учебной базы;
- пользоваться конструктором запросов;
- хранить все упражнения в одном списке;
- сохранить весь список запросов, параметры и настройки в один файл для сдачи.
